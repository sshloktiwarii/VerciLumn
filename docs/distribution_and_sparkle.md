# VerciLumn Production Distribution & Sparkle OTA Update Guide

## 1. Code Signing & Hardened Runtime
To distribute VerciLumn outside the Mac App Store without triggering Gatekeeper malware blocks, the application must be signed with a valid Apple Developer ID Certificate with Hardened Runtime enabled.

### Signing Command
```bash
# Sign bundle with entitlements and hardened runtime
codesign --deep --force --verify --verbose \
  --options runtime \
  --entitlements VerciLumn.entitlements \
  --sign "Developer ID Application: Your Name (TEAM_ID)" \
  VerciLumn.app
```

## 2. Apple Notarization
Submit the signed `.zip` or `.dmg` to Apple's Notary Service:
```bash
# Submit for notarization
xcrun notarytool submit VerciLumn.zip \
  --apple-id "your-apple-id@example.com" \
  --password "app-specific-password" \
  --team-id "TEAM_ID" \
  --wait

# Staple notarization ticket to the app
xcrun stapler staple VerciLumn.app
```

## 3. Sparkle 2.x Over-The-Air (OTA) Updates
VerciLumn uses Sparkle for seamless background updates:

### Configuration in Info.plist:
- `SUFeedURL`: `https://raw.githubusercontent.com/sshloktiwarii/VerciLumn/main/appcast.xml`
- `SUPublicEDKey`: Ed25519 public key generated by `bin/generate_keys`
- `SUEnableAutomaticChecks`: `<true/>`

### Generating AppCast Releases:
```bash
# Generate Sparkle signature and update appcast.xml
./bin/generate_appcast ./releases/
git add appcast.xml && git commit -m "release: v1.0.1 Sparkle AppCast"
git push origin main
```
